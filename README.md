# Календарь

Личный календарь (ПК + телефон), работает в браузере без сборки.

## Запуск
- Быстро: двойной клик по `index.html` (Google-вход и установка как приложение не работают).
- Полностью: в папке выполнить `python -m http.server 8080`, открыть http://localhost:8080 и нажать «Установить» в адресной строке.

## Возможности
- Дни/недели/месяц, перетаскивание, растягивание, создание мышью, быстрый ввод («сдать лабу завтра 15:00 #учёба»).
- Повторы: ежедневно, по дням недели (выбор), ежемесячно, ежегодно; правка «только это / это и следующие / все».
- События «весь день», ключевые события (коллоквиум, экзамен, дедлайн) помечены ⚑ и попадают в «Ближайшие дедлайны».
- Ссылка на заметку Obsidian у события (в настройках — имя хранилища).
- Напоминания (всплывающие и системные), работают пока календарь открыт.
- Поиск: `/` или Ctrl+K. Клавиши: ←/→, t, n, d/w/m.
- Телефон: тот же адрес, интерфейс адаптируется (нижняя навигация, повестка дня, кнопка «+»).

## Google Calendar
Настройки → Google Calendar. Нужен свой Client ID:
1. console.cloud.google.com → создать проект.
2. APIs & Services → включить Google Calendar API.
3. OAuth consent screen → External, добавить свой Gmail в Test users.
4. Credentials → OAuth client ID → Web application, Authorized JavaScript origins: `http://localhost:8080`.
5. Вставить Client ID в настройки, нажать «Войти через Google».

Синхронизация двусторонняя, основной календарь. При конфликте побеждает версия из приложения. Повторы Google, которые приложение не умеет (например «первый понедельник месяца»), показываются только для чтения. Для телефона приложение нужно разместить по https.
