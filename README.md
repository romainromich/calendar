# Календарь

Личный календарь (ПК + телефон), работает в браузере без сборки.

## Запуск
- Быстро: двойной клик по `index.html` (Google-вход и установка как приложение не работают).
- Полностью: в папке выполнить `python -m http.server 8080`, открыть http://localhost:8080 и нажать «Установить» в адресной строке.

## Возможности
- Дни/недели/месяц, перетаскивание, растягивание, создание мышью, быстрый ввод («сдать лабу завтра 15:00 #учёба»).
- Повторы: ежедневно, по дням недели (выбор), ежемесячно, ежегодно; правка «только это / это и следующие / все».
- События «весь день», ключевые события (коллоквиум, экзамен, дедлайн) помечены ⚑ и попадают в «Ближайшие дедлайны».
- Ссылка на заметку Obsidian у события (в настройках — имя хранилища).
- Напоминания (всплывающие и системные), работают пока календарь открыт.
- Поиск: `/` или Ctrl+K. Клавиши: ←/→, t, n, d/w/m.
- Телефон: тот же адрес, интерфейс адаптируется (нижняя навигация, повестка дня, кнопка «+»).

## Google Calendar
Настройки → Google Calendar. Нужен свой Client ID:
1. console.cloud.google.com → создать проект.
2. APIs & Services → включить Google Calendar API.
3. OAuth consent screen → External, добавить свой Gmail в Test users.
4. Credentials → OAuth client ID → Web application, Authorized JavaScript origins: `http://localhost:8080`.
5. Вставить Client ID в настройки, нажать «Войти через Google».

Синхронизация двусторонняя, основной календарь. При конфликте побеждает версия из приложения. Повторы Google, которые приложение не умеет (например «первый понедельник месяца»), показываются только для чтения. Для телефона приложение нужно разместить по https.

## Push-уведомления при закрытом приложении
Сервер лежит в `cloudflare/worker.js` (бесплатный Cloudflare Worker + KV + Cron Trigger раз в минуту). В приложении: Настройки → Push-уведомления → Включить. Работает на Android в Chrome, на iPhone только после добавления на экран «Домой».

## Дизайн H (мобильный)
- Экран «День»: линия времени, карточка «идёт сейчас» с прогрессом, «Окно N мин» с подсказкой задачи, полоса недели с нагрузкой, свайп влево/вправо меняет день.
- Плавающее меню (День, Неделя, Месяц, Задачи, Привычки) и кнопка «+».
- Цветовые схемы (Мята и сирень по умолчанию, Янтарь, Индиго, Лайм, Роза): Настройки → Цвета и тема.
- Поле «Доп. информация / заметка» у события показывается строкой под названием.
- «Начало семестра» в настройках включает номер учебной недели и числитель/знаменатель.
- На компьютере тот же стиль H: плавающие стеклянные панели, пилюли, день как линия времени (неделя и месяц — сетки с перетаскиванием).
- Светлые версии схем: «Мята · день», «Янтарь · день», «Индиго · день», «Лайм · день», «Роза · день» (Настройки → Цвета и тема).
- На телефоне при прокрутке контент уходит под тёмный градиент, день недели закреплён сверху.
- Меню на телефоне — нижняя шторка «Ещё» (кнопка ☰): мини-календарь, календари-чипы, Google, переключатель день/ночь и настройки. Закрывается смахиванием вниз, по тапу на фон или Esc.
- Диалоги (событие, настройки, поиск) в стиле H: на телефоне выезжают шторкой снизу, на ПК — по центру. Метки событий в неделе на ПК — без бокового очерка, с мягкой рамкой.

## Резервная копия и перенос (backup.js)
- Настройки → «Резервная копия и перенос»: сохранить файл, отправить (на телефоне), загрузить из файла.
- В файл попадают события, задачи, привычки, календари, вид. Вход в Google и push — на каждом устройстве свои.
- Загрузка: предпросмотр, «Добавить к текущим» (по id, ничего не теряется) или «Заменить всё». Перед этим делается копия, в тосте есть «Отменить».
- Автокопия раз в день в браузере (последние 6), откат из настроек. Копии делаются и перед очисткой и сбросом.
- Запрос защиты хранилища (`navigator.storage.persist`) и напоминание, если файл не сохраняли 3 недели.

## Подготовка к ключевым событиям (prep.js)
- В диалоге ключевого события (коллоквиум, экзамен, дедлайн…) есть кнопка «Подготовка».
- Задаёшь часы (по умолчанию 8 для экзамена/коллоквиума, 3 для остального) и выбираешь план: «Спокойно» (блоки 1,5–2 ч, по одному в день за 14 дней) или «Плотно» (до 2,5 ч, до двух в день, последние 7 дней).
- Блоки идут в свободные окна с 9:00 до 21:00, вечер (после 14:00) в приоритете, вокруг событий отступ 10 минут. Можно снять галочки с лишних, потом «Поставить». «Отменить» убирает поставленное.
- Блоки помечены `prepFor`, повторный запуск заменяет прежние.

## Закрытие окон
На ПК любое окно (настройки, событие, подготовка, импорт) закрывается кликом по затемнённому фону, как по Escape. Если зажать кнопку внутри окна и отпустить снаружи (например, при выделении текста), окно не закроется. На телефоне не работает, чтобы случайно не потерять ввод.

## Длительность задач
- При добавлении задачи можно выбрать время (15 мин … 3 ч); в списке оно меняется чипом рядом со сроком («+ время», если не задано).
- Подсказка «Успеть» в окне между событиями берёт задачу, которая помещается по времени: сначала по сроку, из подходящих самую крупную. Задачи без времени считаются подходящими для любого окна.

## «Пора выходить» (поля «Место» и «Дорога» у события)
- В диалоге события: место (текст) и время в дороге (5 мин … 1,5 ч). Время для места запоминается и подставляется само при следующем вводе того же места.
- Уведомление «Пора выходить» приходит за дорогу плюс запас на сборы (в «Настройках → Напоминания»: ровно в момент выхода / за 5 / 10 / 15 минут; по умолчанию 5). Работает и как push при закрытом приложении (то же расписание, что у обычных напоминаний).
- В расписании дня под событием видно место и «выйти в 9:30». Место и дорога хранятся только в приложении и в Google не уходят.

## Голосовой ввод (voice.js)
- Кнопка микрофона в поле быстрого ввода (если браузер умеет распознавать речь; Chrome/Android, речь обрабатывает сервис браузера).
- Говоришь «завтра в три линал» — событие создаётся тем же разбором, что и быстрый ввод, с кнопками «Отменить» и «Изменить». Часы 1–7 без уточнения понимаются как дневные (15:00), «в 7 утра» и «в 7 вечера» учитываются. Если времени не назвали, откроется форма с уже понятым.

## Привычки в линии дня
У привычки можно задать время (при добавлении или чипом в списке привычек). Привычка со временем встаёт в «День» между событиями, отмечается там же; привычки без времени остаются только на вкладке «Привычки». Отмечать можно сегодня и прошлые дни.

## Итоги недели (review.js)
- «Ещё» → «Итоги недели»: сколько занятий проведено и задач выполнено, блоки подготовки, привычки по дням и серии, следующая неделя (ключевые события, задачи со сроком). В воскресенье после 12:00 окно открывается само один раз (отключается в «Настройках»).
- Кнопка «Записать расписание в Obsidian» создаёт или перезаписывает заметку (по умолчанию «Календарь/Неделя», путь в настройках): события этой и следующей недели с `[[ссылками]]` на заметки событий, задачи и серии привычек. Текст идёт через буфер обмена, так что на длину ссылки ограничений нет; буфер при этом перезаписывается.
- Задачи теперь запоминают дату выполнения (`doneAt`), поэтому в итогах считаются только задачи, отмеченные после этого обновления.

## Заметка события в Obsidian
«Создать» теперь кладёт в заметку шапку (свойства: событие, дата, время, календарь, место). Кнопка «Дописать актуальные данные в заметку» добавляет в конец заметки блок с текущими данными события (например, после переноса).

## Обновления и кэш
Скрипты и стили подключаются с `?v=NN` (то же число стоит в `sw.js` как `V`), сервис-воркер проверяет свежесть файлов при каждом запросе. При каждом изменении кода поднимать `NN` в index.html и `V` в sw.js, иначе телефон может получить новый index.html вместе со старым app.js.

### Шторка «Ещё» (телефон)
Четыре плитки 2×2: Итоги недели, Google Calendar, Тема, Настройки. Список календарей-фильтров из шторки убран: видимость каждого календаря теперь переключается галочкой «Показывать в календаре» в Настройках → Календари.

### Офлайн
Все файлы приложения кэшируются сервис-воркером при первом открытии, данные лежат в localStorage, поэтому календарь открывается и работает без сети (в том числе по адресу с «?…»). Без сети внизу появляется плашка «Нет сети — работаю офлайн», при возвращении сети — тост. Не работают только Google-синхронизация и push, они догонят сами, когда сеть вернётся. Проверка: открыть сайт один раз с сетью, выключить интернет, перезагрузить страницу.

### Фокус на текущем событии («барабан»)
Вкладка «День» при открытии сама прокручивается к текущему событию (или ближайшему, если сейчас пауза). Строки у центра экрана чёткие, к краям уменьшаются, слегка наклоняются и становятся прозрачнее; на телефоне сверху и снизу добавлены мягкие градиенты. При «уменьшении движения» в системе остаётся только прозрачность. Код: focus.js.
