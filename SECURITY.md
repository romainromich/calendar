# Безопасность «My Calendar»

## Где что хранится

| Что | Где | Насколько секретно |
|---|---|---|
| Ключ подписи APK и пароль | GitHub Secrets + личная копия владельца | Секрет. С ним можно выпустить «обновление» приложения |
| Код доступа к серверу (`OWNER`) | Секрет воркера в Cloudflare + localStorage устройств | Секрет. С ним можно писать на сервер и управлять тестировщиками |
| Токены тестировщиков | KV (только хэш) + localStorage их устройств | Личные. Отзываются кнопкой «Отключить» |
| Ключ синхронизации | localStorage устройств + личная копия | Секрет. С ним можно прочитать календарь из облака |
| Google OAuth Client ID | `sync.js` | Не секрет: публичный по устройству OAuth, секрета клиента нет |
| Токен Google | localStorage, живёт 1 час | Только этого браузера, обновляется входом |
| Данные календаря | localStorage браузера; в облаке — только шифротекст | Личные |

## Если что-то утекло

**Ключ подписи APK**
1. Создать новый ключ, заменить четыре секрета `KEYSTORE_*`/`KEY_*` в GitHub.
2. Заменить отпечаток в `romainromich.github.io/.well-known/assetlinks.json`.
3. Собрать APK, удалить старое приложение на телефоне, поставить новое (данные в браузере не пропадут).

**Код доступа к серверу**
1. Придумать новый длинный случайный код (32+ символа).
2. В Cloudflare: воркер `calendar-push` → Settings → Variables and Secrets → заменить `OWNER`.
3. На своих устройствах: Настройки → Доступ к серверу → «Выйти», затем войти с новым кодом. Тестировщиков это не затрагивает.

**Токен тестировщика утёк** — Настройки → Доступ к серверу → «Отключить» напротив человека, затем выслать ему новое приглашение.

**Ключ синхронизации**
1. Сохранить копию в файл.
2. На всех устройствах: «Отключить» синхронизацию, затем на одном — «Включить» (появится новый ключ), на остальных — «Подключить» с новым ключом.
3. Старые данные под прежним ключом останутся в KV как шифротекст; их можно удалить в Cloudflare → KV (ключи `d:…`).

**Аккаунт Google**
1. myaccount.google.com → Безопасность → сменить пароль, проверить устройства.
2. «Сторонние приложения с доступом» → отозвать доступ календаря, затем войти заново в приложении.

**Аккаунт GitHub**
1. Сменить пароль, проверить двухфакторный вход и сессии (Settings → Sessions).
2. Проверить последние коммиты в `calendar` и `romainromich.github.io` и отозвать лишние токены и приложения (Settings → Applications, Developer settings → Tokens).
3. Если сайт подменили — откатить коммит; приложение подтянет исправленную версию при следующем запуске.

**Аккаунт Cloudflare**
1. Сменить пароль, включить двухфакторный вход.
2. Сверить код воркера с `cloudflare/worker.js` из репозитория и задеплоить заново, заменить `OWNER` и VAPID-ключи.

## Восстановление данных
- «Отменить» после удаления, переноса и правки (8 секунд).
- Автокопии на устройстве раз в день: Настройки → Резервная копия → «Автокопии».
- Файл копии (можно с паролем): Настройки → Резервная копия → «Загрузить из файла».
- Раз в месяц стоит проверять, что последний файл копии открывается.
